# Pokédex texts

What the Pokédex info screen shows for a species, where it comes from, and how species 650-1023 were filled in
(2026-10-15).

## How the game finds the texts

The info screen (decomp `src/ov296/zukan_info.c`, `ZukanInfo_PrintEntry`) reads four system text banks by message
index, and a missing index prints as an empty string (`GFL_MsgDataLoadStrbuf` clears the buffer past a bank's end):

| Bank | Text | Index |
|---|---|---|
| 464 | category ("Seed Pokémon") | species |
| 451 | height (`2'04"`) | message |
| 471 | weight (`15.2 lbs.`) | message |
| 442 | description (up to 3 lines, 221 px: the window is 28 x 7 tiles, text at x 2, y 5) | message |

`message` is the species, then one step through the form chain table per form number: archive `a/0/9/7` member 0,
one u16 per index holding its next form's index (0 = none, the form uses its species' entry). Uncaught Pokémon show
entry 0 of each bank.

## W2U's layout

- 0-649: retail's entries, as W2U has them.
- 650-1023: the expansion species (description, category, height, weight; see below).
- 1024-1106: retail's form entries (Unown, Castform, Deoxys, Burmy / Wormadam, Shellos, Rotom, Giratina, Shaymin,
  Arceus, Basculin, Darmanitan, Deerling / Sawsbuck, the Forces of Nature, Kyurem, Keldeo, Meloetta, Genesect),
  moved from retail's 650-732 because W2U's species own those indices. 464 has no form entries (category is by
  species), and keeps W2U's Egg / Bad Egg at 1024 / 1025.
- The form chain (`data/pokedex/form_name_table.bin`, 1107 entries, staged by the build into `vfs/data/a/0/9/7` with
  `tools/mkdata/stage_narc_members.py`) is retail's, renumbered to 1024+. Species 650+ have no chain yet: their forms
  (regional forms, Megas, ...) show the species' entry.

## Species 650-1023

Source: PokeAPI's data (github.com/PokeAPI/pokeapi, `data/v2/csv`: flavor texts, genera, heights and weights; the
texts are the games' own Pokédex entries). Generated by `w2u-local/dexdata/build_dex_text.py` (local tooling):

- category: the English genus; height and weight converted to retail's formats (feet / inches, pounds to 0.1).
- description: the newest English entry (Scarlet / Violet, Legends: Arceus, Brilliant Diamond / Shining Pearl,
  Sword / Shield, Let's Go, Ultra Sun / Ultra Moon, Sun / Moon, Omega Ruby / Alpha Sapphire, X / Y) that fits three
  lines in the game font; older entries are the fallback when a newer one is too long. 253 species have a whole
  entry. When no entry fits, the most complete one whose leading sentences fit (later sentences dropped): 106. When
  even one sentence is too long: that sentence condensed by hand (15: Aromatisse, Inteleon, Orbeetle, Ursaluna,
  Sneasler, Quaxwell, Pawmo, Bellibolt, Maschiff, Shroodle, Capsakid, Flamigo, Farigiraf, Iron Leaves,
  Poltchageist). The font has no em dash, en dash or minus sign: they become " - " / "-".
- Per-species choices (game, shortened / edited) are listed in MegaB2W2 `research/w2u/dex_report_2026-10-15.tsv`.

Checked on the built ROM (`w2u-local/dexdata/verify_dex_rom.py`, replaying the lookup above): retail species and
forms unchanged in content (Giratina Origin 22'08" / 1433.0 lbs., Shaymin Sky 1'04" / 11.5 lbs.), species 650-1023
filled; every description within 221 px and 3 lines.
